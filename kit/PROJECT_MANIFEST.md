# Project Manifest

## Canonical project name

QuickCart Intelligence Platform

## Canonical one-line description

A local-first end-to-end quick-commerce lakehouse, analytics, ML, RAG, and agentic AI learning platform built with Python, SQL, PySpark, Delta Lake, streaming, CDC, and human-approved operational actions.

## Current active phase on first handoff

Phase 0 — Repository and development environment.

## First major milestone

Phase 4 — A reproducible Bronze → Silver → Gold Delta Lake pipeline built from simulated PostgreSQL business data.

## Final milestone

A user can ask why a simulated store is unhealthy, the agent can ground the answer in Gold metrics and ML predictions, retrieve an SOP when needed, create a structured operational proposal, and execute only after human approval, with an audit trail.
